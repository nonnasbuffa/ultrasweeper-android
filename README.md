# UltraSweeper for Android

A customizable, offline minesweeper with a modern look and a Windows XP-style legacy look,
2 player mode, a tutorial, background music, custom songs and skins, local leaderboards and more.

## Download

Go to **[Releases](../../releases/latest)**, download **UltraSweeper.apk** on your phone and open it.

- If Android asks, allow installing apps from your browser or file manager.
- To update, install the newer APK the same way. Your stats and settings stay.

## Publishing a new version

1. Replace `UltraSweeper.apk` with the new build.
2. Commit and push.
3. Push a new tag, for example `git tag v1.2.1` then `git push origin v1.2.1`.

GitHub then publishes the APK as a new Release automatically.
